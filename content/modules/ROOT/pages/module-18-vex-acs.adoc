= 7.2 VEX blast radius + ACS
:description: Show Lightwell GAV-bound remediation evidence and ACS for both tags

On this page you report blast radius from the remediated pin and leave Advanced Cluster Security on. Skipping ACS fails the module story.

== Why this control exists

A GAV-bound VEX (or the advisory evidence Lightwell publishes after disclosure) explains whether the pin closed the vulnerability. ACS shows runtime and image risk for the same digests. Both consoles are required.

== Learning objectives

* Open ACS Central for the stock and Lightwell image tags
* Tie the `.rhlw-*` pin back to remediations available
* Close with one sentence: Network is post-disclosure; Premier reuses this chain
