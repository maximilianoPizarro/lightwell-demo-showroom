= 3.3 Live Renovate
:description: Name Renovate as the pin-update path without merging a live PR

On this page you name how a new Network or Premier pin arrives without a hand-edit. You do not merge a live Renovate pull request during the ten-minute walk.

== Why this control exists

Hand-editing pins does not scale. Renovate (MintMaker in some engagements) opens a pull request when a new `.rhlw-*` coordinate is available. During an embargo, merge the pin and keep advisory text out of a public pull-request description. This hub has no embargo exercise and no live bot PR in the spoken path.

== Learning objectives

* Name Renovate as the automated pin path
* State that a hand-edit of the same file is not the Check this track wants in a full workshop
* Keep the ten-minute walk free of a live merge
